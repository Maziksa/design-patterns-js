# Design Patterns - Geometric Shapes

Приложение для работы с геометрическими фигурами с использованием паттерна Factory Method.

## Описание

Проект реализует обработку геометрических фигур (прямоугольники и конусы) с чтением данных из файлов, валидацией и вычислением характеристик.

## Технологии

- TypeScript 5.9.3
- Node.js
- Jest (тестирование)
- ESLint (Airbnb стандарт)
- Pino (логирование)

## Паттерны и принципы

- **Factory Method Pattern** - создание объектов через фабрики
- **SOLID принципы** - разделение ответственности
- **GRASP паттерны** - Information Expert, Creator, Low Coupling

## Варианты задания

- **Вариант 2**: Прямоугольник (площадь, периметр, проверки на квадрат/ромб/трапецию)
- **Вариант 8**: Конус (объем, площадь поверхности, рассечение плоскостью)

## Особенности реализации

- Entity-классы содержат только данные без бизнес-логики
- Service-классы инкапсулируют все вычисления
- Валидаторы обеспечивают проверку корректности данных
- Обработка некорректных данных с логированием ошибок
- Покрытие тестами ~89%
