# Design Patterns — Graph Structures

## Описание

Приложение моделирует работу с графами, позволяя создавать сложные иерархические структуры (графы, подграфы, вершины, ребра) и гибко менять способ их хранения в памяти.

## Технологии

- **TypeScript**
- **Node.js**

### 1. Bridge

Отделяет абстракцию графа от реализации его хранения. Это позволяет менять структуру данных "под капотом", не ломая клиентский код.

- **Abstraction**: `Graph` — высокоуровневый интерфейс для работы с графом.
- **Implementor**: `IGraphStorage` — интерфейс хранилища.
- **Concrete Implementations**:
  - `AdjacencyMatrixStorage` — хранение через матрицу смежности.
  - `AdjacencyListStorage` — хранение через списки смежности.

### 2. Composite

Позволяет сгруппировать узлы в подграфы и работать с группами так же, как с одиночными объектами.

- **Component**: `GraphComponent` — общий интерфейс.
- **Composite**: `Subgraph` — контейнер, который может содержать вершины, ребра и другие подграфы.
- **Leaf**: `Vertex`, `Edge` — конечные элементы графа.

### 3. Builder / Static Factory

Класс `DemoScenarioBuilder` инкапсулирует логику создания сложных тестовых сценариев.
